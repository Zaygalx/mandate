Let agents spend.
On your terms. Spend limits, human approvals and an audit grade ledger for AI agents that pay with PayPal.

An agent with a card is a liability. An agent with a mandate is a colleague. Mandate evaluates every purchase against a deterministic policy before a PayPal order exists, escalates what needs a human, and writes a hash chained record of everything.

Read the code Watch the demo Try the live console
Recorded against the built in mock driver, so the whole flow runs without credentials. Set PAYPAL_MODE=sandbox to place real Orders v2 calls. Direct MP4 also available: mandate-demo.mp4.

One policy, three surfaces

Decide

Six ordered rules, a pure function, no model in the payment path. Same input, same answer, every time.

Approve

Above the threshold, policy escalates. A human mints a single use token that expires in fifteen minutes.

Prove

Every decision, order, capture, refund and approval is chained by hash. Edit one row and verification breaks.

The console

Intents carry the rule that decided them. The ledger carries the PayPal order and capture identifiers. The audit trail carries the chain.

The approval moment

The token is shown once, stored as a SHA-256 hash, bound to one intent, and refused on replay.

What the agent sees

Over MCP, a purchase returns one of three outcomes. The agent cannot approve itself, and a denial means no PayPal call was ever made.

{
  "status": "captured",          "paid": true,   "capture_id": "MOCK-CAPTURE-..."   // within the mandate
}
{
  "status": "awaiting_approval", "paid": false,  "intent_id": "int_...",
  "code": "APPROVAL_REQUIRED"                                                        // a human must say yes
}
{
  "status": "denied",            "paid": false,  "code": "PER_TX_CAP"               // before any order exists
}

Run it

git clone https://github.com/Zaygalx/mandate
cd mandate
node --test          # 25 tests, no credentials
node scripts/demo.mjs
node src/server.mjs  # http://localhost:8787
  • Node 24 or newer, zero dependencies thanks to node:sqlite
  • Mock PayPal driver by default; PAYPAL_MODE=sandbox for real sandbox orders
  • MCP server at src/mcp.mjs for any MCP capable agent
